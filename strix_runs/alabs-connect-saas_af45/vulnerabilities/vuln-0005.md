# next: Next.js: Denial of Service via crafted requests to App Router with Server Actions

**ID:** vuln-0005
**Severity:** HIGH
**Found:** 2026-08-08 09:29:06 UTC
**Target:** /workspace/alabs-connect-saas
**Package:** next
**Ecosystem:** npm
**Installed Version:** 15.5.19
**Fixed Version:** 15.5.21, 16.2.11
**CVE:** CVE-2026-64641
**CWE:** CWE-834
**CVSS:** 7.5
**Fix Effort:** Low

## Description

Next.js is a React framework for building full-stack web applications. In versions 13.0.0 through 15.5.20 and 16.0.0 through 16.2.10, crafted requests targeting Next.js applications using App Router with at least one Server Action can lead to excessive CPU usage blocking processing of further requests in the same process. This issue has been fixed in versions 15.5.21 and 16.2.11.

## Evidence

**Advisory evidence:** `CVE-2026-64641` applies to `next` at installed version `15.5.19`. The advisory is fixed in `15.5.21, 16.2.11`.

**Usage analysis:** imported by application code; affected API usage unconfirmed. Package 'next' appears to be imported or required in the source code. This is a prioritization signal from static analysis, not a proof of exploitability or of safety.

## Impact

The vulnerability in `next` can lead to high impact.

## Remediation

Upgrade `next` to version `15.5.21, 16.2.11` or higher.

## Assumptions

This finding is based on static analysis of package-lock.json. Dynamic validation was not performed.
